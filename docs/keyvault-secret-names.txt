===============================================================================
Azure Key Vault - Secret Names for Duke MJE Automation Services
===============================================================================

Vaults to provision (one per environment):
  - duke-mje-dev-kv  -> https://duke-mje-dev-kv.vault.azure.net/
  - duke-mje-stg-kv  -> https://duke-mje-stg-kv.vault.azure.net/
  - duke-mje-prod-kv -> https://duke-mje-prod-kv.vault.azure.net/

Naming convention:
  Application env-var  ->  Key Vault secret name
  (UPPER_SNAKE_CASE)       (lower-dash-case)

  Example: AZURE_OPENAI_API_KEY -> azure-openai-api-key

Place EVERY secret below in EACH of the three vaults (with the
appropriate per-env value).


===============================================================================
SECRETS (provision in dev, stg, prod)
===============================================================================


# ---- Azure OpenAI -----------------------------------------------------------

azure-openai-api-key
    Env var : AZURE_OPENAI_API_KEY
    Source  : Azure OpenAI resource > Keys & Endpoint > Key 1
    Used by : ALL services
    Sensitive: YES


azure-openai-endpoint
    Env var : AZURE_OPENAI_ENDPOINT
    Source  : Azure OpenAI resource > Keys & Endpoint > Endpoint URL
              (e.g. https://duke-mje-dev-openai.openai.azure.com/)
    Used by : ALL services
    Sensitive: NO (URL only) -> stored in KV for centralized config


azure-openai-deployment-name
    Env var : AZURE_OPENAI_DEPLOYMENT_NAME
    Source  : Azure OpenAI > Deployments > <deployment name>
              (e.g. gpt-4o)
    Used by : 5 agent services (cog, gas, icdeccin, itft, shared)
    Sensitive: NO -> stored in KV for centralized config


azure-openai-deployment
    Env var : AZURE_OPENAI_DEPLOYMENT
    Source  : Same value as azure-openai-deployment-name
              (api-service uses the shorter env-var name)
    Used by : api-service
    Sensitive: NO


azure-openai-api-version
    Env var : AZURE_OPENAI_API_VERSION (and OPENAI_API_VERSION)
    Value   : 2025-01-01-preview (current); confirm latest stable
    Used by : api-service + 5 agent services
    Sensitive: NO


# ---- Azure Storage (Blob) ---------------------------------------------------

azure-storage-connection-string
    Env var : AZURE_STORAGE_CONNECTION_STRING
    Source  : Storage account > Access keys > Connection string
    Used by : 5 agent services (file ingest + output)
    Sensitive: YES

    NOTE:
    STRONGLY PREFER replacing this with Managed Identity +
    "Storage Blob Data Contributor" RBAC on the storage account.
    If MI is used, this secret can be SKIPPED entirely.


azure-storage-account-name
    Env var : AZURE_STORAGE_ACCOUNT_NAME
    Value   : e.g. dukemjedevsa
    Used by : 5 agent services (only consulted when conn string absent)
    Sensitive: NO


azure-storage-input-container
    Env var : AZURE_STORAGE_INPUT_CONTAINER
    Value   : duke-inputs (default; override per env if needed)
    Used by : 5 agent services
    Sensitive: NO


azure-storage-output-container
    Env var : AZURE_STORAGE_OUTPUT_CONTAINER
    Value   : duke-outputs (default; override per env if needed)
    Used by : 5 agent services
    Sensitive: NO


# ---- API Service: Database --------------------------------------------------

database-url
    Env var : DATABASE_URL
    Format  : postgresql://duke:<postgres-password>@<host>:<port>/duke_db
    Used by : api-service ONLY
    Sensitive: YES (contains password)


postgres-password
    Env var : POSTGRES_PASSWORD
    Source  : Provisioned with the PostgreSQL instance for the 'duke' user
    Used by : api-service ONLY
    Sensitive: YES


postgres-user
    Env var : POSTGRES_USER
    Value   : duke
    Used by : api-service ONLY
    Sensitive: NO


postgres-db
    Env var : POSTGRES_DB
    Value   : duke_db
    Used by : api-service ONLY
    Sensitive: NO


# ---- API Service: Authentication / JWT --------------------------------------

jwt-secret
    Env var : JWT_SECRET
    Source  : Generate with 'openssl rand -base64 48'
              MUST be different per environment.
    Used by : api-service ONLY
    Sensitive: YES


# ---- API Service: pgAdmin (optional sidecar) -------------------------------

pgadmin-password
    Env var : PGADMIN_PASSWORD
    Source  : Operator-chosen password for pgAdmin web UI
    Used by : api-service (only if pgAdmin sidecar is deployed)
    Sensitive: YES

    NOTE: OPTIONAL -> only required if pgAdmin is included in deployment.


pgadmin-email
    Env var : PGADMIN_EMAIL
    Value   : admin@duke.ey.com (or operator email)
    Used by : api-service (pgAdmin sidecar)
    Sensitive: NO


===============================================================================
QUICK SUMMARY - what to create in EACH vault (dev / stg / prod)
===============================================================================

REQUIRED (sensitive secrets):

  1. azure-openai-api-key
  2. azure-storage-connection-string
       (skip if Managed Identity is used)
  3. database-url
       (api-service only -> but populate in all envs)
  4. postgres-password
       (api-service only)
  5. jwt-secret
       (api-service only)
  6. pgadmin-password
       (only if pgAdmin is deployed)


CONFIG CENTRALIZED IN KV (not strictly secret but stored for consistency):

  9.  azure-openai-deployment
  10. azure-openai-api-version

Total per vault: up to 16 entries
Total across 3 vaults: up to 48 entries
